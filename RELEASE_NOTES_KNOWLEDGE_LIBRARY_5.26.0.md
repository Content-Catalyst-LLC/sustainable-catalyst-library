# Sustainable Catalyst Knowledge Library v5.26.0

**Release:** Multimodal Scientific Document Intelligence  
**WordPress plugin:** 5.26.0  
**Python backend:** 2.37.0

## Added

- Scientific Document Intelligence contract and normalization runtime.
- First-class figure, chart, table, equation, caption, appendix, supplement, and dataset objects.
- Source page, bounding-box, source-locator, source-content-hash, caption, and verification provenance.
- Structured table preservation with row/column counts and supplied cells.
- Source equation preservation for LaTeX, MathML, or extracted expressions.
- Supplied chart/figure data-series preservation without pixel-value inference.
- Exact in-text scientific cross-reference detection against supplied scientific-object labels.
- Source-span graph nodes for explicit references in publication chunks.
- Scientific-document graph overlay integrated into the publication corpus.
- Research Graph Query and Evidence Pathfinding support for scientific objects.
- WordPress REST proxy for scientific-document intelligence.
- Knowledge Landscape **Scientific Objects** view and object/relationship filters.
- JSON schemas for scientific objects and scientific-document intelligence.

## Preserved

- v5.25.0 deterministic Research Graph Query & Evidence Pathfinding.
- Analytical similarity/co-occurrence remains opt-in for evidence paths.
- v5.24 cross-publication synthesis and competing-hypothesis boundaries.
- v5.24.0.1 release-certification compatibility behavior.
- Support and contradiction require explicit reviewed relationships.
- Evidence weight is not truth.
- Absence of contradiction is not agreement.
- Platform Core remains the durable authority for governed research objects and synthesis.

## Interpretation boundaries

v5.26.0 does not infer numeric values from chart pixels, invent missing units or labels, automatically verify OCR text, solve equations, infer causal meaning, or promote scientific objects into claims. Scientific-document objects remain documentary/source objects until an explicit governed workflow promotes related evidence into Platform Core.
