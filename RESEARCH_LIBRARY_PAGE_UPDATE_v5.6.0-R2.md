# Research Library page update — v5.6.0 R2

Use `RESEARCH_LIBRARY_PAGE_v5.6.0-R2.html` only after installing the **5.6.0.2** WordPress plugin.

R2 keeps the restored Library as the source-of-truth capability set while changing the visual hierarchy. Knowledge Base, Library Access and Research Librarian are featured immediately below the hero. The complete Library Capability Map remains below them and shows one group at a time.

## Safe rollout

1. Keep the restored live Research Library page unchanged.
2. Install the v5.6.0.2 plugin.
3. Create a Draft or Private WordPress page.
4. Paste the complete R2 page HTML into the test page.
5. Verify the three featured front doors, Knowledge Explorer, all six capability tabs, representative protected deep links and the bounded capability workspace.
6. Only after visual approval, replace the live page body. WordPress revisions remain the rollback path.

The plugin never automatically overwrites the Research Library page.
