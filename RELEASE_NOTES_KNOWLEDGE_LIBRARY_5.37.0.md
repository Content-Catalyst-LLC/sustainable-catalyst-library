# Sustainable Catalyst Library v5.37.0

**Release:** Research Corpus Builder & Dataset Export  
**Backend:** 2.48.0  
**Go ingestion runtime:** 0.1.0  
**Rust graph runtime:** 0.2.0

This release adds reproducible corpus assembly and portable dataset export. Researchers can build deterministic corpora from explicit record sets, inclusion/exclusion IDs and descriptive source/topic/date/status filters; inspect the resulting selection decisions and manifest fingerprints; and export projected datasets as JSON, JSONL, CSV or a multi-format bundle.

Every dataset row carries source-record provenance. Corpus inclusion remains a research-selection state—not a quality score, truth judgment, consensus claim or Platform Core promotion.
