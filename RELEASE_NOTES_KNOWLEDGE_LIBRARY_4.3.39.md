# Sustainable Catalyst Library v4.3.39 — Research Portability & Preservation

- Adds `[sc_research_portability]`.
- Adds authenticated `/wp-json/sc-library/v1/research-portability/catalog`, `/export`, and `/validate`.
- Exports one owned Research Project as a references-first JSON package with stable identities and SHA-256 integrity.
- Includes Source Bundle manifests, project-linked Reading Notebooks, Evidence Matrices, and learning routes.
- Supports complete and manifest-only profiles.
- Excludes private source binaries, credentials, secrets, raw WordPress tables, and local file paths.
- Adds non-executing integrity validation; no records are imported or created.
- Keeps the established institutional preservation subsystem authoritative for server archive snapshots.
- No automatic publication, evidence promotion, record mutation, or Workspace write.
