# Knowledge Library v5.22.0 — Visual Evidence Traceability & Source Drilldown

A visual research object is useful only when a researcher can explain why it is present. v5.22.0 adds a source-grounded trace from selected publications and topics back to Library records, source passages, explicit citations, accepted reviewed research candidates, and the measured relationship basis used by the visualization.

The trace is descriptive. It does not create new claims, convert similarity into truth, or imply causality. Source passages are excerpts and reviewed candidates remain source-bound unless separately promoted through governed Platform Core workflows.

Contract: `sc-library-visual-evidence-trace/1.0`

Endpoint: `POST /v1/publication-knowledge-maps/evidence-trace`
