# Research Library page update — v5.6.0 R1

Use `RESEARCH_LIBRARY_PAGE_v5.6.0-R1.html` only after installing the v5.6.0.1 WordPress plugin.

The page keeps the Knowledge Base visible, keeps pathways and applied-product handoffs visible, and delegates the complete capability inventory to `[sc_library_capability_hub]`. The hub does not delete the old applications; it lazy-mounts their existing shortcodes when opened.

Before replacing page content, preserve the current WordPress revision. The plugin does not modify the page automatically.

If rollback is needed, restore the prior WordPress page revision and keep the plugin active; the existing legacy shortcodes continue to work.
