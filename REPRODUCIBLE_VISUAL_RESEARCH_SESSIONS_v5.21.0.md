# Knowledge Library v5.21.0 — Reproducible Visual Research Sessions & Workspace Handoff

This release makes linked visual analysis reproducible. A researcher can save and reopen the current view, visual query, selected nodes/regions/year, relationship filters, terrain elevation metric, camera, and viewport. The backend can package that state with a content-hash-based corpus fingerprint and source-record references.

Workspace handoff packages are references-only and require explicit acceptance. They do not automatically write into Workspace, mutate Library sources, promote claims, or convert selections into research conclusions.
