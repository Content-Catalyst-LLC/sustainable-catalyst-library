# Sustainable Catalyst Knowledge Library 5.38.0

## Unified Research Runtime Contract

This release introduces a governed runtime layer spanning Python, Go, and Rust without collapsing their responsibilities.

### Added

- Unified runtime discovery/status contract.
- Runtime descriptors for Python backend, Go ingestion fabric, and Rust graph runtime.
- Deterministic runtime routing decisions.
- Explicit compatible fallback policy.
- Signed unified execution endpoint.
- Common execution envelope with request/result fingerprints.
- WordPress runtime-status and route-resolution console.
- Publication-corpus map surface for unified runtime discovery.
- JSON schemas for the runtime contract and execution envelope.

### Preserved

- Python backend 2.49.0 as research-semantics/provenance/routing authority.
- Go ingestion runtime 0.1.0 with state-file durability.
- Rust graph runtime 0.2.0 with analytical-edge opt-in.
- Research Corpus Builder & Dataset Export from v5.37.0.
- Platform Core as durable governed research-object authority.

### Not claimed

v5.38.0 does not claim that outputs from different runtimes are scientifically equivalent. It does not silently reroute incompatible work, does not turn runtime success into evidence truth, and does not automatically promote runtime outputs into Platform Core.
