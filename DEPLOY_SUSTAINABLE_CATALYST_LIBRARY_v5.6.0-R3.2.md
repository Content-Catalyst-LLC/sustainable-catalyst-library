# Deploy Sustainable Catalyst Library v5.6.0 R3.2

1. Install/push the repository payload using `install_and_push_sustainable_catalyst_library_v5_6_0_r32_macos.sh`.
2. Upload `sustainable-catalyst-library-v5.6.0-R3.2-wordpress.zip` in WordPress and replace the installed plugin.
3. Confirm the plugin reports **5.6.0.32**.
4. Update the Research Library page with `RESEARCH_LIBRARY_PAGE_v5.6.0-R3.2.html`.
5. Flush WordPress cache and hard-refresh.
6. Verify:
   - Three Research Front Doors are three clean navigation cards;
   - Knowledge Explorer topic chips are visible;
   - Capability Map Open actions are visible;
   - Knowledge Pathways renders as a two-column interface;
   - Account Continuity is a compact utility strip;
   - Open Courses is visible;
   - university/public-library research access still works.

Backend v1.1.0 remains unchanged.
