# Release Notes — Sustainable Catalyst Library v5.8.0

## Biomedical & Clinical Evidence Intelligence Foundation

- Backend advances to 1.3.0.
- Native PubMed and PMC discovery through NCBI E-utilities.
- Native ClinicalTrials.gov API v2 study discovery.
- MeSH 2026 descriptor resolution.
- RxNorm drug-concept resolution.
- Normalized biomedical evidence/concept contracts with provenance and bounded handoff metadata.
- Unified biomedical search endpoint with source-level failure containment.
- New `[sc_biomedical_evidence]` WordPress surface.
- ClinicalTrials.gov, MeSH, and RxNorm become visible Research Network sources; PubMed/PMC retain their existing network identity.
- No database migration.
- Research-only governance boundary is explicit throughout the API and UI.
