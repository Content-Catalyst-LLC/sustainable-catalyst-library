# Sustainable Catalyst Knowledge Library v5.48.0

**Title:** Cross-Language Entity, Name & Historical Toponym Resolution  
**Python backend:** 2.59.0  
**Go ingestion runtime:** 0.1.0  
**Rust graph runtime:** 0.2.0

This release adds multilingual authority/name forms, historical toponym validity windows, deterministic resolution cases and candidates, explicit transliteration-form support, ambiguity preservation, and signed explicit resolution decisions.

Resolution scores are analytical ranking signals only. The release performs no automatic entity merge, translation, transliteration, evidence promotion, truth promotion, or Platform Core promotion.
