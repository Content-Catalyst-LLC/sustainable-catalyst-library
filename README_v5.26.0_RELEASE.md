# Sustainable Catalyst Knowledge Library v5.26.0

**Release:** Multimodal Scientific Document Intelligence  
**WordPress:** 5.26.0  
**Python backend:** 2.37.0

This release makes structured scientific material a first-class part of the Knowledge Library research graph: figures, charts, tables, equations, captions, appendices, supplements, datasets, and exact in-text source references.

The release deliberately does not infer chart values from pixels, promote OCR text to verified evidence, or treat a scientific object's presence as proof of a claim. Platform Core remains the durable authority for governed research objects and synthesis.
