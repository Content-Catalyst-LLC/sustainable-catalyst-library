# Sustainable Catalyst Library Backend v2.10.0

Backend v2.10.0 activates Energy Systems Intelligence v0.4.0 — Renewable Technology & Resource Model.

It preserves all existing Library, private knowledge, institutional, biomedical, Carbon & Nature v0.5.0, Energy Systems v0.2.0 numeric, and v0.3.0 indicator behavior while adding GET-only renewable technology/resource registries and assessment/observation contracts.

No PostgreSQL schema migration is required for this release. No current renewable resource or technology-performance dataset is loaded.
