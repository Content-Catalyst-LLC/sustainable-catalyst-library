# Release Notes — Carbon & Nature Intelligence v0.3.0

## Carbon Evidence & Methodology Graph

Carbon & Nature v0.3.0 advances the Library-native AFOLU/Nature-Based Solutions line from a measure registry into a provenance-ready research graph.

### Added

- 7 governed methodology profiles
- 4 initial evidence/reference objects
- 175 typed evidence-methodology graph edges on the packaged seed set
- methodology and evidence list/detail APIs
- graph filtering and node-neighborhood APIs
- evidence/methodology context on measure detail
- Research Librarian handoff packets containing concepts, measures, methodologies, evidence, and graph relationships
- WordPress Evidence & Methodology Graph explorer while preserving the Measure Registry

### Preserved boundaries

No automatic methodology selection, evidence-quality grade, claim validation, sequestration calculation, project eligibility, credit issuance, certification, or project-specific MRV protocol generation.

### Versions

- Sustainable Catalyst Library: 5.11.0 application line preserved
- Carbon & Nature Intelligence: 0.3.0
- Library backend: 2.4.0

### Migration

No PostgreSQL schema migration and no new API credentials.
