# Release Notes — Carbon & Nature Intelligence v0.2.0

**Release:** Carbon Sequestration Measure Registry  
**Primary home:** Sustainable Catalyst Library v5.11.x  
**Backend:** 2.3.0

v0.2.0 builds directly on the AFOLU & Nature-Based Solutions Knowledge Foundation. It introduces ten structured sequestration/land-management measure profiles with stable identity, land-system applicability, carbon-pool and GHG linkage, outcome types, MRV families, integrity dimensions, co-benefit/risk contexts, evidence requirements, bounded filtering, measure detail, and non-ranking comparison packets.

Research-context packets now carry measure matches for downstream Research Librarian evidence retrieval, while AFOLU-specific domain reasoning remains reserved for v0.5.0.

This release intentionally contains no generic sequestration factors, project scoring, credit eligibility, automatic methodology selection, SOC calculator, whole-farm GHG calculator, or certification behavior.
