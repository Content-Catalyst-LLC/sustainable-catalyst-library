# Research Library Page Update — v5.6.0 R3

R3 is intended to replace the R2 preview only after visual review. It should not automatically overwrite the live Research Library page.

## Safer rollout

1. Install WordPress Library v5.6.0.3.
2. Create a Draft or Private test page.
3. Paste the complete contents of `RESEARCH_LIBRARY_PAGE_v5.6.0-R3.html` into the code editor.
4. Verify the Research Network Console, direct university search, University College Dublin, Public Library Network, Find a Library Near You, Access Intelligence, Research Librarian, Knowledge Explorer and expanded capability directory.
5. Compare the preview with the restored live Library.
6. Only after approval, replace the existing page body while keeping the canonical page URL.

The restored v5.4 baseline is included in the release for rollback/reference.
