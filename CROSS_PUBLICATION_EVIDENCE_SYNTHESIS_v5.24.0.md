# Cross-Publication Evidence Synthesis & Competing Hypotheses — v5.24.0

## Purpose
Turn accepted, reviewed finding/claim overlays into auditable cross-publication synthesis structures without creating new scholarly conclusions in the Library.

## Contract
`sc-library-cross-publication-evidence-synthesis/1.0`

## Outputs
- support-connected reviewed structures (descriptive graph components, not consensus)
- explicit contradiction pairs
- cross-publication support/contradiction summaries
- source-grounded argument paths
- explicit hypothesis nodes and membership edges when reviewed metadata supplies a hypothesis key/id
- competing-hypothesis sets only when reviewed metadata explicitly supplies the shared competing-set key

## Interpretation boundaries
- consensus is not inferred
- hypotheses are not inferred
- competition is not inferred
- evidence balance is not a truth score
- contradiction still requires an explicit reviewed relation
- the Library performs source-grounded descriptive synthesis and visualization
- Platform Core remains authoritative for governed claims/findings/arguments and durable cross-study synthesis
