# Sustainable Catalyst Library v4.3.23-r1

**Release type:** installer/validation repair  
**Product version:** 4.3.23 (unchanged)

v4.3.23-r1 repairs the v4.3.23 macOS installer after a false-negative DOCX regression failure on PHP environments using `ZipArchive`.

The original test required a generated DOCX fixture to exceed 5,000 bytes. Because DOCX is a compressed OOXML ZIP package, valid output size varies by ZIP backend. A 3,706-byte DOCX generated by `ZipArchive` failed the threshold even though the package was valid.

r1 removes the size assumption and validates package integrity and required OOXML content directly. It also records the active ZIP backend and makes the installer explicitly safe to rerun from the partially-applied v4.3.23 working tree left by the failed installer.

There are **no runtime feature changes**. Research Document Builder, DOCX/PDF export behavior, Citation Studio, Course Finder, Research Access, Research Librarian, and the v4.3.22.4 Publications 14-field stack are preserved.
