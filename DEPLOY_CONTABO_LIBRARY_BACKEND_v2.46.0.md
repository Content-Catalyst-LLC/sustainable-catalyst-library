# Deploy Library Backend v2.46.0

Upload `sustainable-catalyst-library-backend-v2.46.0.zip` and `upgrade_library_backend_v2_46_0_contabo.sh` to `/tmp`, then run:

```bash
sudo ./upgrade_library_backend_v2_46_0_contabo.sh /tmp/sustainable-catalyst-library-backend-v2.46.0.zip
```

The installer performs a no-cache Docker build, verifies Rust runtime 0.2.0, runs a forced native structural neighborhood query, a forced native structural-statistics query, existing Rust evidence pathfinding, and Platform Core readiness.
