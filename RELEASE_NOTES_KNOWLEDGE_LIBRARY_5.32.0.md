# Sustainable Catalyst Knowledge Library v5.32.0
## Rust Research Graph Runtime Foundation

Pairs WordPress plugin **5.32.0** with Python backend **2.43.0** and native Rust graph runtime **0.1.0**.

Adds a versioned native graph contract, Rust bounded pathfinding executable, multi-stage Docker build, Python native-runtime adapter and fallback, runtime-aware evidence pathfinding (`auto`, `rust`, `python`), native runtime health endpoint, WordPress proxy/status console, and runtime provenance in pathfinding responses.

Research semantics remain in Python. Platform Core remains the durable authority for governed research objects and synthesis.
