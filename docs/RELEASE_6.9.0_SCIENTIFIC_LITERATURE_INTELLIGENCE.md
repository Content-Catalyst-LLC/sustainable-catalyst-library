# Sustainable Catalyst Library v6.9.0 — Scientific Literature Intelligence

## Generations
- Library: 6.9.0
- Python backend: 3.9.0
- Independent Web: 2.9.0
- Python SDK / JavaScript client: 1.9.0
- Optional WordPress adapter: 6.9.0
- Database migration: none

## Purpose
v6.9.0 turns existing scientific-document, literature-review, citation/provenance, discovery, and structured-evidence capabilities into one Library-native scientific-literature intelligence layer.

## New objects
- Scientific publication profile
- Scientific literature set
- Scientific citation-context summary
- Scientific literature validation envelope

## Capabilities
- DOI, PMID, PMCID, arXiv, ISSN and ORCID normalization
- author and affiliation normalization
- study-design indicators with explicit source basis and review-required state
- correction / retraction / expression-of-concern metadata slots
- scientific-object composition from existing document intelligence
- literature-set deduplication and coverage summaries
- reproducible literature-review composition using the existing review engine
- structured dataset previews through v6.8 structured evidence
- citation-context summaries without support/quality inference

## Guardrails
Citation count is not quality. Journal venue is not quality. A detected study-design phrase is not a definitive classification. Extracted or supplied claims are not truth. Review inclusion is not truth and exclusion is not falsehood. Retraction/correction metadata is only as complete as the supplied or verified source. No automatic meta-analysis, consensus inference, truth promotion, evidence promotion, or Platform Core promotion occurs.
