# Library v6.21.0 — Research Question & Investigation Workspace

Library v6.21.0 adds an investigation-control layer that turns an explicit research question into a reproducible investigation structure without becoming an autonomous research agent.

Generations: Library 6.21.0 / Backend 3.21.0 / Web 2.21.0 / SDK 1.21.0 / API v1 stable.

Public route: `/research/investigation`.

API base: `/api/library/v1/research-investigation`.

Capabilities include research-question framing, subquestions, hypotheses, evidence needs, source strategy, dependency-aware tasks, decision points, stop conditions, risk/bias register, coverage analysis, reproducible export, and signed handoff previews to existing research project, saved-search, research-queue, and retrieval-plan authorities.

The workspace does not execute searches or tasks automatically. Hypotheses are not claims, evidence, or truth. Task completion is not evidence. Search/retrieval results are not promoted automatically. Priorities and stop conditions do not determine truth. No automatic source trust, hypothesis adjudication, claim/evidence/truth promotion, or Platform Core promotion occurs.

No database migration. WordPress remains optional/non-authoritative.
