# Library v7.0.0 — Independent Knowledge Library Platform

Library 7.0.0 promotes the production-certified 6.x architecture into a stable independent product baseline.

## Generations

- Library 7.0.0
- Backend 4.0.0
- Library Web 3.0.0
- Python / JavaScript / TypeScript SDK 2.0.0
- API v1.0 remains the stable service boundary

## Release intent

This is a promotion and stabilization release, not a new feature family. It freezes the independent-library architecture around Python/FastAPI runtime authority, PostgreSQL structured research state, the first-party Library Web public origin, direct SDK clients, and an optional non-authoritative WordPress adapter.

## Stability policy

The 7.0 line enters maintenance mode after production certification. 7.0.x patches are reserved for bugs, security, deployment repairs, and required integration fixes. No 7.1 feature line is implied by this release.

## Preserved surfaces

The full 6.x research stack remains available, including research packages, publication studio, knowledge graph, Workspace integration, project/lineage/review workspaces, portable exchange, collaborative rooms, Librarian intelligence, cross-institution federation, and reproducibility/audit.

## Guardrails

API v1 remains stable. No destructive database migration is required. WordPress remains optional and non-authoritative. Runtime or release success does not imply source validity, evidence strength, scientific validity, or truth. No automatic external fetch, re-execution, truth promotion, or Platform Core promotion is introduced.
