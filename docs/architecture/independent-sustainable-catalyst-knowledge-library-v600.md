# Knowledge Library v6.0.0 — Independent Sustainable Catalyst Knowledge Library

v6.0.0 changes the product hierarchy.

The Knowledge Library is now an independent primary Sustainable Catalyst application. WordPress is an optional publishing, routing, SEO, embed, editorial and compatibility adapter.

## Product generations

- Library: 6.0.0
- Backend: 3.0.0
- Independent Web: 2.0.0
- Python/JavaScript/TypeScript SDK: 1.0.0
- API: v1 (preserved)

## Authoritative runtime

API v1 -> Python/FastAPI -> PostgreSQL, workers, artifacts, pipelines, federation and governed Platform Core exchanges.

Library-native identity/session/access remains authoritative for Library sessions.

The first-party independent web application calls API v1 directly.

## WordPress

WordPress may publish, route, expose SEO metadata, provide embeds, display status and retain legacy presentation compatibility. It is not required for Library research state, identity/session authority, execution, federation, search, provenance, language intelligence, reproducibility, workflows or cross-product clients.

## Compatibility

API v1 remains stable. The 6.0 major version is an architectural/product-generation cutover, not an API-v1 breaking change.

No destructive database migration is required for the 6.0 cutover.
