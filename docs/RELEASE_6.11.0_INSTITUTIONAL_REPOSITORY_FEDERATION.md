# Sustainable Catalyst Library v6.11.0 — Institutional Repository Federation

Library 6.11.0 / backend 3.11.0 / Web 2.11.0 / SDK 1.11.0.

This release promotes the existing institutional research network into a Library-native repository federation composition layer. It reuses MIT DSpace, Harvard Dataverse, Johns Hopkins Dataverse, and UCD OAI-PMH connectors; preserves source-local failures and provenance; consolidates exact DOI observations; creates deterministic repository snapshots; and exposes explicit import handoffs.

OAI-PMH remains bounded metadata harvesting rather than an arbitrary full-text search API. Repository visibility is not endorsement, affiliation, access entitlement, reuse permission, evidence quality, or truth. No external record is automatically imported, promoted to evidence, or promoted to Platform Core.

No database migration is required. WordPress remains an optional adapter.
