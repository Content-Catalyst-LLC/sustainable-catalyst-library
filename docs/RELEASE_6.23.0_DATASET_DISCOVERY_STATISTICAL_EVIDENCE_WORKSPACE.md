# Library v6.23.0 — Dataset Discovery & Statistical Evidence Workspace

Library v6.23.0 adds a researcher-facing quantitative evidence workspace over existing Structured Evidence, Scientific Literature, Global Federation, Research Investigation, and Evidence Matrix layers.

Generations: Library 6.23.0 / Backend 3.23.0 / Web 2.23.0 / SDK 1.23.0 / API v1 stable.

Public route: `/research/data`.
API base: `/api/library/v1/statistical-evidence`.

Capabilities include metadata-based dataset discovery, dataset profiles, variable dictionaries, units and denominators, study design and population context, normalized statistical results, uncertainty audits, effect-size preservation, multiple-comparison and missing-data context, dataset/statistical gap analysis, reproducible JSON export, and non-executing handoff previews to Evidence Matrix and Research Investigation.

The workspace never interprets p-values, confidence intervals, correlations, sample size, model fit, or effect sizes as automatic truth, practical significance, validity, or causality. Dataset ranking is metadata matching only. No automatic external fetch, evidence promotion, claim adjudication, or persistence occurs.

No database migration. WordPress remains optional/non-authoritative.
