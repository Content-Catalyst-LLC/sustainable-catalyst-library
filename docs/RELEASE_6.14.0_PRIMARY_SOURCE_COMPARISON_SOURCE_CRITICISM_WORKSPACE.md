# Library v6.14.0 — Primary-Source Comparison & Source Criticism Workspace

Library v6.14.0 turns the comparison capabilities introduced in v6.12–v6.13 into a dedicated scholarly source-criticism workspace at `/research/archives/compare`.

## Added
- structured ten-dimension source-criticism rubric;
- provenance-aware source analysis without authenticity/reliability scoring;
- side-by-side comparison matrix;
- explicit human-asserted source relationships;
- claim/source corroboration ledger with support, contradiction, contextualization, silence and ambiguity observations;
- unresolved-question preservation;
- standalone web comparison workspace;
- Python and JavaScript client methods.

## Guardrails
Agreement is not independence. Corroboration counts are not truth probabilities. Contradictions are not falsity scores. Provenance completeness does not certify authenticity. OCR/HTR/transcription/translation remain derived representations. No automatic ranking, adjudication, reconciliation, evidence promotion, truth promotion, or Platform Core promotion occurs.
