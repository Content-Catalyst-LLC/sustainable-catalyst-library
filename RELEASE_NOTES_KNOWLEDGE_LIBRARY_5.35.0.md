# Release Notes — Knowledge Library 5.35.0

## Rust Evidence Graph Acceleration & Native Query Engine

This release upgrades the native graph runtime to 0.2.0 and adds policy-filtered structural query operations for neighborhoods, reachability, connected components, induced subgraphs, and descriptive graph statistics. Existing bounded evidence pathfinding remains compatible.

Python continues to select relationship classes before native execution and retains provenance, evidence semantics, interpretation guardrails, and Platform Core handoff authority. Analytical/similarity edges remain opt-in.
