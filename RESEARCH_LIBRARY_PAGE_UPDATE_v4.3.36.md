# Research Library Page Update — v4.3.36

Replace the body of the canonical `/knowledge-libraries/` WordPress page with `RESEARCH_LIBRARY_PAGE_v4.3.36.html`.

## Change

Open Learning II is embedded inside the existing Open Learning / Open Course Finder section rather than adding another large standalone page section. The new shortcode is `[sc_open_learning_ii title="Open Learning II — Build a Learning Route"]`.

The planner reuses the reviewed Open Course Finder launch catalog, Knowledge Pathway mappings, provider registry, and existing My Learning states. It sequences courses using declared level plus deterministic metadata relevance. Missing prerequisite or duration data remains explicitly unknown.

Signed-in users can save private learning-route manifests and optionally associate them with owned Research Projects, Source Bundles, or Reading Notebooks. Saving a route does not enroll the user, purchase a course, award a certificate, alter third-party accounts, or mark a course complete.

The Publications page does not require replacement.
