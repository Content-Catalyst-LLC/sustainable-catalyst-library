# Release Notes — Sustainable Catalyst Library v5.6.0 R3

**Release:** v5.6.0 R3 — Visible Research Network, University Search & Local Library Access  
**WordPress version:** 5.6.0.3  
**Python backend:** 1.1.0 (unchanged)

## Added

- Research Network Console driven from the existing university, scholarly and public-library registries.
- Direct visible Research Access section.
- Direct visible Institutional Research Network.
- Direct visible Public Library Network & Local Access.
- Prominent Find a Library Near You route.
- Direct visible Access Intelligence II.
- Full visible Research Librarian section in addition to the top front door.
- Expanded capability-directory mode so the rest of the Library is visibly listed instead of hidden one group at a time.
- Individual capability exclusions to prevent duplicate anchors when a capability is already directly rendered.
- R3 visual density stylesheet and research-network console styling.
- Visibility-tier regression tests.

## University College Dublin

UCD is retained as a first-class direct research source. Research Repository UCD / DSpace discovery remains searchable through the Research Access connector stack and appears visibly in the university source layer.

## Public library access

The existing local/public library network remains intact and visible, including New York Public Library and the WorldCat nearby-library route. Sustainable Catalyst stores connected-library relationships only; it does not store library passwords or infer entitlement from catalog availability.

## Preservation

The restored v5.4 Library remains the source of truth: 37 protected shortcodes and 72 protected anchors remain under regression protection.
