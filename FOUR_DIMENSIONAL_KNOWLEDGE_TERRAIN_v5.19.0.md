# Knowledge Library v5.19.0 — 4D Knowledge Terrain & Temporal Dynamics

v5.19.0 converts the multi-publication analytical structures introduced in v5.18.0 into a renderer-neutral four-dimensional knowledge-terrain contract for the Research Library.

## Dimensions

- X: deterministic topological region separation derived from measured topic-region structure.
- Y: deterministic within-region placement for source-grounded topics and concepts.
- Z: a selectable normalized analytical elevation metric.
- T: publication year.

The initial Z metrics are relationship density, publication density, and temporal activity.

## Renderer

The Research Library shortcode `[sc_library_knowledge_landscape]` now exposes a **4D Knowledge Terrain** view. The view uses a scientific terrain canvas with orbit, zoom, elevation selection, year scrubbing, and time playback. It is linked to the same source-grounded publication corpus used by the existing graph, topic-region, timeline, citation, semantic, and matrix views.

## Research integrity

Terrain elevation does not represent truth. Spatial proximity does not imply causality. Topic regions remain deterministic analytical groupings based on measured relationships. Time is publication time. Semantic similarity is only included when current stored embeddings exist.

## Platform Core

The Library owns source ingestion, corpus preparation, measured topic structure, and Research Library rendering. Platform Core remains the governed authority for reusable visual research objects, provenance, linked views, visual query, scene graphs, and cross-product exchange.
