# Sustainable Catalyst Library v4.3.36 — Open Learning II

Open Learning II adds deterministic learning-route planning above the existing Open Course Finder and v4.3.21 My Learning state system. It reuses the reviewed launch catalog, provider registry, Knowledge Pathways, and `sc_library_course_plan_v4321` rather than creating a second course database.

The new planner ranks course matches transparently, sequences them from declared course-level labels, displays the catalog review date, and treats missing prerequisite/duration metadata as unknown rather than inferred. Signed-in users can save private, checksummed route manifests and optionally attach them to owned Research Projects, Source Bundles, or Reading Notebooks.

A saved learning route is a Sustainable Catalyst planning record, not third-party enrollment. Sustainable Catalyst does not purchase courses, store provider passwords, award certificates, infer completion, or guarantee current price/access/enrollment conditions. The provider/course page remains authoritative.
