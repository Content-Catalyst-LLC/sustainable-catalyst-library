# Release Notes — Knowledge Library v5.48.0

## Added
- Cross-language entity authority objects.
- Multilingual name/alias/variant/endonym/exonym/transliteration forms.
- Historical toponym validity windows and query-year ranking signals.
- Deterministic resolution cases and candidate provenance.
- Explicit signed resolution decisions with rationale and adjudicator metadata.
- Research Corpus Builder fields for resolution case/entity/decision lineage.
- WordPress readiness status and administrator-only stateless resolution proxies.

## Guardrails
Candidate score is not probability; candidate rank is not identity or truth. No automatic entity merge, resolution, translation, transliteration, evidence promotion, truth promotion, or Platform Core promotion occurs.
