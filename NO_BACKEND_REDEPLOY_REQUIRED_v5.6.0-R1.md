# Backend status for v5.6.0 R1

The v5.6.0 R1 repair changes the WordPress/page presentation layer only. The Python backend remains **v1.1.0**.

If `/health` already reports version `1.1.0`, no Contabo backend deployment is required for R1.

The release still includes a v1.1.0 backend package for completeness and for installations that never deployed the original v5.6.0 backend.
