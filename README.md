# Sustainable Catalyst Library v5.16.0 — Publication Visualization Foundations

Knowledge Library v5.16.0 advances the shared Python backend to **v2.27.0** and makes publication knowledge visualizations first-class Research Library objects. It adds reviewed Citation Network, Concept Map, Finding Map, and Claim Map specifications, plus a WordPress rendering surface through `[sc_library_publication_visualizations]`.

The Library owns source-derived visualization composition and Research Library delivery. Platform Core owns governed visual research objects, visual reasoning, provenance, reproducibility, cross-product composition, and exchange. No visualization in this release infers truth, invents citation relationships, or automatically promotes claims/findings.

See `PUBLICATION_VISUALIZATION_FOUNDATIONS_v5.16.0.md`, `RELEASE_NOTES_KNOWLEDGE_LIBRARY_5.16.0.md`, and `DEPLOY_CONTABO_LIBRARY_BACKEND_v2.27.0.md`.

# Sustainable Catalyst Library v5.15.0 — Entity, Finding & Claim Extraction

Knowledge Library v5.15.0 advances the shared Python backend to **v2.26.0** and adds source-anchored extraction candidates for entities, findings, and claims. Candidates remain Library-owned and explicitly non-governed until human review. Accepted finding/claim candidates can then be queued through the v5.12 durable Platform Core outbox into Core v3.3+ Finding, Claim & Evidence Intelligence.

Library owns source ingestion, parsing, chunking, retrieval, citation extraction, and candidate extraction. Platform Core owns governed findings/claims, provenance/lineage, evidence relationships, synthesis, reproducibility, visual reasoning, statistical reasoning, and cross-product exchange. No extraction candidate is treated as truth, scientific validity, or a governed research conclusion.

See `ENTITY_FINDING_CLAIM_EXTRACTION_v5.15.0.md`, `RELEASE_NOTES_KNOWLEDGE_LIBRARY_5.15.0.md`, and `DEPLOY_CONTABO_LIBRARY_BACKEND_v2.26.0.md`.
