# Sustainable Catalyst Knowledge Library v5.30.0 Release

**Release:** Evidence Quality & Methodology Intelligence  
**WordPress:** 5.30.0  
**Backend:** 2.41.0

## Install order

1. Run `install_and_push_sustainable_catalyst_library_v5_30_0_macos.sh` to validate, commit, tag, and push the repository release.
2. Copy `sustainable-catalyst-library-backend-v2.41.0.zip` and `upgrade_library_backend_v2_41_0_contabo.sh` to `/tmp` on Contabo and run the backend installer.
3. Upload `sustainable-catalyst-library-v5.30.0.zip` in WordPress and replace the existing plugin.

The backend v2.41.0 verification must pass before moving to the next Knowledge Library release.
