# Deploy Library Backend v2.31.0

From the Mac, copy `sustainable-catalyst-library-backend-v2.31.0.zip` and `upgrade_library_backend_v2_31_0_contabo.sh` to `/tmp` on the Contabo VPS. Run the installer there. It preserves `.env`, creates a pre-deploy backup, rebuilds the Docker service, waits for health, then verifies linked scientific views, the visual-query contract, 4D terrain preservation, Platform Core readiness, and hybrid retrieval.

`PASS: Library backend v2.31.0 Linked Scientific Views & Visual Query deployed.`
