# Sustainable Catalyst Knowledge Library v5.29.0 Release

**Release:** Temporal Knowledge & Research Evolution  
**WordPress:** 5.29.0  
**Backend:** 2.40.0

## Install order

1. Run `install_and_push_sustainable_catalyst_library_v5_29_0_macos.sh` to validate, commit, tag, and push the repository release.
2. Copy `sustainable-catalyst-library-backend-v2.40.0.zip` and `upgrade_library_backend_v2_40_0_contabo.sh` to `/tmp` on Contabo and run the backend installer.
3. Upload `sustainable-catalyst-library-v5.29.0.zip` in WordPress and replace the existing plugin.

The v2.40.0 backend verification must pass before moving to the next Knowledge Library release.
