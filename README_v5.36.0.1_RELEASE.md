# Knowledge Library v5.36.0.1 Release

This release contains WordPress plugin v5.36.0.1, Python backend v2.47.1, Go ingestion runtime v0.1.0 and Rust graph runtime v0.2.0.

Use `install_and_push_sustainable_catalyst_library_v5_36_0_1_macos.sh` for repository validation/Git release and `upgrade_library_backend_v2_47_1_contabo.sh` for the Contabo backend deployment.

The backend deployment is required. It builds both native runtimes and adds the internal `sc-library-ingestion` service plus its durable queue volume.
