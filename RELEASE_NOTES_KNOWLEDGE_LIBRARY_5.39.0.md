# Knowledge Library v5.39.0 — Cross-Runtime Reproducibility & Execution Lineage

Backend: **v2.50.0**. Go ingestion runtime remains **v0.1.0**. Rust graph runtime remains **v0.2.0**.

This release extends the Unified Research Runtime Contract with replayable execution records, runtime/environment fingerprints, explicit parent-child lineage, same-runtime replay verification, and descriptive cross-runtime output comparison for workloads that genuinely have multiple implementations.

## Guardrails
Matching normalized outputs are reported as an observed reproducibility match, not proof of scientific equivalence, truth, quality, consensus, or causal validity. Different outputs do not prove one runtime is wrong. Platform Core remains the durable authority for governed research objects.
