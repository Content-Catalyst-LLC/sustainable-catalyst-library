# Release Notes — Sustainable Catalyst Knowledge Library v5.20.0

**Release:** Linked Scientific Views & Visual Query  
**Backend:** v2.31.0

Highlights:
- adds renderer-neutral linked visual-query contract `sc-library-linked-visual-query/1.0`;
- adds portable shared query state across scientific views;
- adds graph-node, region, relationship-matrix, time, text, and 4D terrain-peak selection;
- adds Highlight and Isolate analytical modes;
- adds deterministic adjacency and cross-filter indexes;
- makes publication-time scrubbing cross-filter the broader analytical environment;
- retains v5.19 4D terrain, v5.18 multi-publication analysis, canonical Publication Library scoping, source provenance, typed relationships, and Platform Core alignment;
- keeps explicit research-integrity boundaries: selection is not a conclusion, adjacency is not causality, and visual queries do not mutate source records.
