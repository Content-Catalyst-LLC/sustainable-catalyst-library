# Release Notes — Sustainable Catalyst Knowledge Library v5.20.0.2

**Release:** Scientific Renderer Visibility & 4D Terrain Recovery  
**Backend:** v2.31.2

This patch repairs the scientific visualization lifecycle observed after v5.20.0.1 production corpus loading. Non-terrain views now hard-hide the 4D canvas and HUD, eliminating canvas overlap. The 4D surface renderer now preserves topic peaks instead of averaging dense anchors into a broad flattened surface, while retaining measured elevation metrics, publication time, topic anchors, publication anchors, linked scientific views, visual query, and asynchronous Publication Library corpus transport.

No automatic claims, causal inferences, semantic-truth promotion, or source mutation are introduced.
