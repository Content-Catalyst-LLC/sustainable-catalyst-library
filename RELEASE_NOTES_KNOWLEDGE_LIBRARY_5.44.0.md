# Sustainable Catalyst Knowledge Library v5.44.0

**Global Source Federation Registry & Connector Contracts**

v5.44.0 establishes the canonical source-identity and connector-contract layer for global research discovery. Backend v2.55.0 normalizes 26 existing research sources into stable institution, source, collection, and connector identities while preserving the existing execution adapters.

### Added

- Global Source Federation Registry (`sc-library-global-source-federation-registry/1.0`).
- Stable institution, source, collection, and connector IDs.
- 26 initial source descriptors and 26 primary connector contracts.
- Explicit connector execution authority and compatibility aliases.
- Capability, authentication-mode, pagination, rate-limit, provenance, and language-preservation declarations.
- Deterministic registry fingerprinting.
- Registry filtering by family, capability, collection, authority, and query text.
- Connector-contract validator with governance checks.
- Backend readiness/source/collection/connector APIs.
- WordPress REST proxies and `[sc_global_source_registry]` surface.

### Preserved

- v5.43 publication embedding maps and semantic Knowledge Landscape.
- v5.42 neural reranking and retrieval evaluation.
- v5.41 semantic similarity and representation search.
- v5.40 governed embeddings and Workspace compute handoff.
- v4.8 federation transport and v2.6 scholarly/library connector execution.
- Go 0.1.0 and Rust 0.2.0 runtimes.

### Guardrails

Registry membership and connector health are descriptive technical signals only. They do not imply source quality, evidence truth, endorsement, partnership, or user trust. v5.44.0 performs no automatic import, evidence promotion, truth promotion, Platform Core promotion, or translation.
