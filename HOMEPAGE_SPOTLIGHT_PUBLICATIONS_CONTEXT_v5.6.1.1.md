# Homepage Spotlight Publications Context — v5.6.1.1

## Recommended homepage shortcode

Replace:

```text
[sc_homepage_spotlight]
```

with:

```text
[sc_homepage_spotlight context="publications"]
```

This changes presentation only. It does not alter spotlight cards, subject pages, source records, editorial scheduling, rotation, or the Research Library homepage console.

## Optional copy overrides

```text
[sc_homepage_spotlight context="publications" title="Publications" intro="Selected public work across Sustainable Catalyst's current fields of inquiry."]
```

## Homepage sequence

Recommended sequence remains:

```text
[sc_homepage_spotlight context="publications"]
[sc_lab_home_preview]
[sc_site_intelligence_home]
[sc_library_homepage_console mode="full"]
```

The Publications spotlight and Research Library console now have distinct public identities.
