# Deploy Knowledge Library backend v2.50.0

Copy `sustainable-catalyst-library-backend-v2.50.0.zip` and `upgrade_library_backend_v2_50_0_contabo.sh` to `/tmp` on Contabo, then run the installer with sudo. The verifier requires Python 2.50.0, Go 0.1.0, Rust 0.2.0, execution-lineage status, signed record/replay verification, corpus export regression, Go durability, Rust native query, and Platform Core readiness.
