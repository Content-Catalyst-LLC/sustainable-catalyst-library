# Sustainable Catalyst Library v4.3.35 — Access Intelligence II

Access Intelligence II adds a ranked access-path layer above the existing v4.3.24 Access Intelligence classifier. It reuses existing holdings, source, Public Library Network, Institutional Connector, and My Libraries contracts.

The release adds transparent route scoring and rank reasons, route confidence, freshness penalties, connected-library fit, explicit entitlement classes, unresolved-question diagnostics, and fallback sequencing. Public fallbacks include WorldCat and Library of Congress searches.

The release does **not** claim that a catalog search proves a holding, that a holding proves user eligibility, or that a saved My Libraries relationship proves active membership or subscription coverage. No external-library credentials are stored. Provider and library sites remain authoritative.

Existing v4.3.34 Metadata Quality, v4.3.33 Workspace Continuity, v4.3.32 Evidence Matrix, v4.3.31 Reading Notebook, v4.3.30 Research Projects/Source Bundles, v4.3.24 Access Intelligence, and the v4.3.22.4 Publications stack are preserved.
