# Deploy Knowledge Library backend v2.35.0

Transfer `sustainable-catalyst-library-backend-v2.35.0.zip` and `upgrade_library_backend_v2_35_0_contabo.sh` to `/tmp`, then run the installer. The installer preserves `.env`, creates a backup, rebuilds `sc-library-backend`, verifies health/version, corpus synthesis contract, visual-query/terrain/session/evidence-trace contracts, Platform Core readiness, and hybrid retrieval.
