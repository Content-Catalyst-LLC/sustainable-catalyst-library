# Knowledge Library Console Presentation Guide

## Sustainable Catalyst Library v4.1.2

The public Homepage Spotlight now behaves like a curated airport information board for Knowledge Library records.

## Recommended homepage shortcode

```text
[sc_homepage_spotlight]
```

Default behavior:

- automatic rotation enabled;
- 14-second interval;
- category tabs enabled;
- previous, pause/play, position, and next controls enabled;
- pause on hover and keyboard focus;
- swipe navigation on touch devices;
- looping enabled; and
- reduced-motion protection enabled.

## Visual roles

- **White:** article titles and primary category headings.
- **Light gray:** summaries and explanatory copy.
- **Medium gray:** record metadata, numbering, and secondary status.
- **Purple:** Knowledge Library identity and selected category.
- **Pink:** position-one feature treatment and article actions.
- **Green:** automatic playback and active operational state.

## Relationship to the homepage

The intended sequence remains:

1. Homepage hero
2. Knowledge Library Console
3. Release Console
4. Live Intelligence

The Knowledge Library Console represents curated research. Release Console represents platform development. Live Intelligence represents current public signals.

## Editorial behavior

The presentation refresh does not change the administration workflow. Continue using **SC Library → Homepage Spotlight** to create categories and select four or five records per category. Existing records are reused automatically after the plugin update.
