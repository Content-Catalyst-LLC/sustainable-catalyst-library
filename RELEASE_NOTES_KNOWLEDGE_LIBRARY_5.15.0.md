# Sustainable Catalyst Knowledge Library v5.15.0

**Release:** Entity, Finding & Claim Extraction  
**WordPress:** 5.15.0  
**Python backend:** 2.26.0

## Added

- source-anchored entity, finding, and claim extraction candidates
- candidate confidence, source locator, chunk ordinal, character span, and source content hash
- deterministic metadata/rule-based extraction
- human review states before Core promotion
- automatic supersession of stale candidates after source content changes
- allowlisted Platform Core finding/claim operations tied to a declared Core research project
- WordPress backend diagnostics for extraction readiness

## Governance boundaries

Candidates are not governed findings or claims. The Library does not infer truth, evidence strength, causality, scientific validity, or consensus. Platform Core does not generate the candidate during promotion; it records an explicitly reviewed candidate as a proposed governed research object.

Entity candidates are retained in the Library in v5.15.0 and are not misrepresented as Core finding/claim objects.

## Preserved

v5.14 citation graph and scholarly lineage, v5.13 hybrid retrieval and Core-aware results, v5.12 durable Platform Core bridge, and all earlier domain capabilities remain preserved.
