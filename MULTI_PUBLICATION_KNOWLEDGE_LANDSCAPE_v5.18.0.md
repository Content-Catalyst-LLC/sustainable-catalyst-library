# Knowledge Library v5.18.0 — Multi-Publication Knowledge Landscape

## Purpose
Turn the canonical Publication Library corpus into a scientific cross-publication analytical landscape.

## New analytical structures
- Deterministic topic regions from repeated measured corpus/source-span co-occurrence.
- Publication-to-publication topic-set Jaccard overlap.
- Explicit citation and real-embedding semantic channels remain separate.
- Publication-year bins and topic trajectories.
- Structural bridge-node diagnostics.
- Sparse relationship-matrix payload for linked views.
- Four-dimensional analytical contract: X/Y structural region space, selectable Z prominence/density, T publication time.

## Integrity boundary
No LLM-inferred edges, guessed citations, truth promotion, or causal interpretation. Topic regions are descriptive graph structures only.

## Platform Core
The Library owns source-grounded corpus construction and display. Platform Core remains the authority for governed visual research objects, provenance, visual reasoning, linked views, visual query, and reproducibility.
